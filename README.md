# 前端宇宙 · 知识闯关 FRONTEND GALAXY

一款太空像素风的「前端知识闯关」网页游戏。驾驶像素飞船穿越 12 个星域，消灭 Bug 怪兽，从零开始通关前端三大基石：HTML、CSS、JavaScript。

**纯前端实现，单文件运行，零依赖，无需安装，双击即玩。**

---

## 游戏简介

你是一名刚入职的见习前端工程师。由于全宇宙的 Bug 怪兽爆发，前端知识星域被黑暗侵蚀。AI 领航员「小C」将陪你驾驶飞船，逐一收复 12 个星域，最终击败盘踞在「全栈黑洞」的终极 Boss。

每一只 Bug 怪兽都对应一道前端选择题：

- **答对**：飞船发射激光消灭怪兽，得分增加，连击有额外加成
- **答错**：怪兽反击，飞船护盾受损，同时显示正确答案与详细解析
- **护盾耗尽**：本关失败，可随时重新挑战，进度不丢失

## 游戏特色

### 对话引导系统

AI 领航员「小C」全程陪伴教学，不只是一道题库：

- **课前预习**：每关开始前 6~10 条剧情对话，用太空冒险故事引出本关主题，并先讲解一遍核心概念
- **逐题讲解**：每答完一题（无论对错），小C 都会弹出对话讲解知识点——为什么对、为什么错，附记忆口诀与生活类比
- **通关总结**：每关结束后回顾本关知识清单，预告下一关内容
- **活泼鼓励**：答错不批评，鼓励话术活泼，穿插程序员梗
- **打字机效果**：对话逐字显示，复古游戏氛围拉满

### 复古像素美术

- 深空蓝黑背景 + 三层视差滚动星空
- 霓虹配色像素飞船与怪兽（参考 Space Invaders / Galaga 街机质感）
- CRT 扫描线 + 暗角效果，还原老式显示器观感
- 每个星域有专属主题色与程序化绘制的像素行星
- 全部像素图形由 Canvas 程序化绘制，**不依赖任何图片资源**

### 8-bit 合成音效

使用 Web Audio API 实时合成，无音频文件：

- 激光声、爆炸声、受击声
- 答对提示音、答错警告音
- 通关胜利音乐、失败音效、战斗 BGM 循环

## 如何运行

下载 `index.html`，双击用现代浏览器打开即可游玩。

## 技术实现

- **单文件架构**：全部代码（HTML + CSS + JS，约 1300 行）在一个 `index.html` 中，关键逻辑附中文注释
- **Canvas 渲染**：960×600 逻辑分辨率，2 倍超采样抗锯齿，`image-rendering: pixelated` 保持像素锐利；窗口等比缩放自适应
- **像素精灵系统**：字符串数组定义精灵 + 色板映射，程序化绘制全部图形
- **音效合成**：Web Audio API 振荡器（方波/锯齿波/三角波）+ 滑音 + 白噪声，实时合成 8-bit 音效与 BGM
- **状态机驱动**：标题 → 星图 → 开场对话 → 战斗 → 讲解 → 总结 → 结算画面，完整流程闭环
- **定时器结算**：命中判定由定时器驱动而非帧循环，后台标签页切回也能正确结算

## 题库扩充

题目以结构化数组管理，新增题目只需在 `LEVELS` 数组对应关卡中追加对象：

```js
{
  q: '题干文字',
  opts: ['选项A', '选项B', '选项C', '选项D'],
  ans: 0,            // 正确答案索引 0-3
  why: '解析：为什么选这个',
  tip: '记忆口诀或生活类比（可选）'
}
```

每个关卡对象包含 `name`（星域名）、`theme`（主题）、`color`（主题色）、`intro`（开场对话数组）、`questions`（题目数组）、`summary`（通关总结对话数组），按同样格式即可添加全新星域。
